Internal root rotation rule

For any three roots of the same cubic-residue target, their ratios are cube roots of unity.

For the T root family:

t1 * t2^-1 mod N = ω2
t1 * t3^-1 mod N = ω2^2
t2 * t3^-1 mod N = ω2

So the internal root rotation is controlled by ω2, not by Λ.

ECDSA scalar stride

The ECDSA equation is:

sk ≡ m + rd mod N

So:

k = (m + r*d) * s^-1 mod N

The scalar stride is:

delta_k = r * s^-1 mod N

delta_k =
42518748094800190364691662520829255725760545190387351376607655495124216557634

This means when d increases by 1, k increases by delta_k modulo N.

Recentered scalar equation

Define the signature ground-zero scalar:

d0 = -m * r^-1 mod N

Then:

d = d0 + Δd

and:

k = Δd * delta_k mod N

This turns the ECDSA scalar line into a centered proportional map.
