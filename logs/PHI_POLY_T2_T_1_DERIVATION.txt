1) Symbolic derivation (identical in both rings)
----------------------------------------------------------------------------------------
--- Ring Z/pZ, root t, lift 1+t+t^2 = p ---
  Polynomial: t^2 + t + 1 == 0 (mod p)
  Integer lifts: check (1+t+t2) % p == 0
  Chosen nonnegative reps: 1+t+t2 == p?  True

  THEOREM (orbit sum).
    Let a in 1..p-1, a1=(t*a) %p, a2=(t2*a) %p.
    Then a + a1 + a2 = q*{name} with q in {1,2}.
  PROOF.
    t*a = k1*{name} + a1,  t2*a = k2*{name} + a2.
    a+a1+a2 = a + t*a + t2*a - (k1+k2)*{name}
             = a(1+t+t2) - (k1+k2)*{name}
             = a*p - (k1+k2)*p   [using 1+t+t2=p]
             = {name}*(a - k1 - k2).
    For a in 1..mod-1, classical floor(y)+floor(z) vs floor(y+z) with
    y=t*a/mod, z=t2*a/mod, y+z = a - a/mod, floor(y+z)=a-1,
    hence a-k1-k2 in {1,2}. QED.

  THEOREM (carry reconstruction; no t^2 mul).
    a1 = (t*a) mod {name}
    q  = 1 if a+a1 < {name} else 2
       = 1 + floor((a+a1)/{name})
    a2 = q*{name} - a - a1
  PROOF.
    From 1+t+t2=0 mod {name}:  t2 == -1-t  =>  t2*a == -a - t*a  (mod {name}).
    So a2 == -(a+a1) (mod {name}).
    Canonical lift in [0,{name}):
      if a+a1 < {name}:  a2 = {name} - (a+a1) = {name}-a-a1  => q=1
      if a+a1 >= {name}: a2 = 2*{name}-(a+a1)           => q=2
    Equiv: q = 1 + floor((a+a1)/{name}), a2 = q*{name}-a-a1.
    Meaning: q is the carry bit of adding a and a1 across {name}. QED.

  COROLLARY.
    Computing t2*a mod {name} is redundant once (a1,q) are known.
    Pipeline: a --*t--> a1 --carry--> q --sub--> a2.
