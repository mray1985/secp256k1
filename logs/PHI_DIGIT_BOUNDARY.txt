3) What is actually changing
----------------------------------------------------------------------------------------
  • Integer x does NOT change under negation.
  • Pure X = x/p digits are identical for P and -P.
  • Combined C = X + Fine: Fine ~ O(1/p) ~ 10^{-78}.
  • Adding Fine can CARRY into the last few digits of the x/p region.
  • So printed C looks like 'x changed around digits 75-78' —
    that is carry from y/p^2 (or (p-y)/p^2), not a new x.
  • True C_neg = x/p + (p-y)/p^2 = x/p - y/p^2 + 1/p.
    Plain (x/p - y/p^2) omits +1/p and is NOT Phi(-P).

  C and X agree on first 77 frac digits: 65/128
  C and X agree on first 78 frac digits: 13/128
