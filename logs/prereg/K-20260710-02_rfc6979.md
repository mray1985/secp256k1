## Strategic boundary (locked)

> A nonce pattern from solved-puzzle spending transactions describes the
> **people/software that spent those coins**, not necessarily the creator of
> the puzzle set.

Therefore:

\[
\boxed{\text{No universal empirical }k\text{-rule may be transferred from heterogeneous puzzle spends to P135.}}
\]

K-02 asks a different question: which rows were generated by the same deterministic signer?

Even exact RFC6979 matches only help P135 if its signature came from that same process.

## Exact hypothesis (locked)

```text
k_det = RFC6979_HMAC_SHA256(d, z)   # secp256k1 order N, SHA-256

match iff  k_det ∈ {k, N-k}
```

The `{k, N-k}` allowance handles low-S normalization without discarding the deterministic hypothesis.

### Procedure (locked — no optional entropy, no alternate encodings)

Per RFC 6979 §3.2 with HMAC-SHA256, q = N (secp256k1 order):

1. Serialize private key `d` as 32-byte big-endian integer in `[1, N-1]`.
2. Serialize message hash `z` as 32-byte big-endian (`bits2octets`: int(z) mod N, then 32-byte BE).
   - Input `z` from panel is already the sighash integer; reduce mod N then 32-byte BE.
3. Run RFC6979 generate_k with hash = SHA-256, no extra entropy.
4. Output `k_det` in `[1, N-1]`.

**FORBIDDEN after peeking:** extra entropy; truncated/left-padded variants; double-SHA; using raw z without mod N; switching hash; post-failure encoding sweeps.
