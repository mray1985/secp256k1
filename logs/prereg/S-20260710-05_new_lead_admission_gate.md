## Immediate rejection (before coding)

Reject when the proposal only provides:

* a score or ranking;
* a resemblance or repeated number;
* a correlation without deterministic exclusion;
* an equation containing the unknown \(d\) or \(k\) but no independent constraint;
* a filter tuned using the target;
* a set whose size cannot be bounded;
* a rule that fails even one locked holdout;
* several overlapping claims whose intersection has not been measured
  (\(b_{A\cap B}=134-\log_2|A\cap B|\), never \(b_A+b_B\) without independence).
