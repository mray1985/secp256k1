========================================================================================
Phi layer invariants: X = x/p, Fine = y/p^2, C = X + Fine
========================================================================================

  Goal: find cheap layer rules / invariants under T_neg, T_lambda, F
  without paying a full EC addition for F itself.

----------------------------------------------------------------------------------------
1) Negation on layers
----------------------------------------------------------------------------------------
  Exact: x' = x, y' = p-y
  => X' = X  (coarse invariant)
  => Fine' = (p-y)/p^2 = 1/p - Fine
  => C' = C + 1/p - 2*Fine

  walk 1..64: X'==X:                    64/64
  walk 1..64: Fine'==1/p - Fine:        64/64
  walk 1..64: C'==C + 1/p - 2*Fine:     64/64
  Cost: split Fine from C (decode y) + one sub; NO field inv, NO EC add.
  Requires Fine (hence y). Digits-only without split: no (float hides Fine).

----------------------------------------------------------------------------------------
2) GLV T_lambda on layers
----------------------------------------------------------------------------------------
  psi: (x,y)->(beta*x mod p, y)
  => Fine' = Fine  (fine layer INVARIANT)
  => X' = (beta*x mod p)/p   NOT equal to (beta*X) mod 1 in general
     (wrap when beta*x >= p)

  walk 1..64: Fine'==Fine:                         64/64
  walk 1..64: X'==(beta*x mod p)/p exact:          64/64
  walk 1..64: X'=={beta*x/p} (frac of beta*X*p?): 64/64
  walk 1..64: times beta*x wrapped (>=1*p):        64/64
  So Fine is GLV-invariant. Coarse needs one mul-mod-p (decode x).
  Still cheaper than scalar*LAMBDA; not a C-digit multiply.

  walk 1..64: Fine invariant under psi^2:          64/64
