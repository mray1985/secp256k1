========================================================================================
Coarse channel: if x1+x2+x3 = p then sum(xi/p) = 1
========================================================================================

----------------------------------------------------------------------------------------
1) Exact identity (any ints)
----------------------------------------------------------------------------------------
  (x1+x2+x3)/p = x1/p + x2/p + x3/p
  so x1+x2+x3 = p  <=>  sum Xi = 1   (exact in Q)
  similarly = 2p <=> sum Xi = 2, etc.

----------------------------------------------------------------------------------------
2) Field relation for beta
----------------------------------------------------------------------------------------
  (1 + beta + beta^2) mod p = 0
  1 + beta + beta^2 (as int) = 115792089237316195423570985008687907853269984665640564039457584007908834671663
  (1+beta+beta^2)/p = 1

----------------------------------------------------------------------------------------
3) GLV triples on nG: S = x + (beta*x mod p) + (beta^2*x mod p)
----------------------------------------------------------------------------------------
  walk 1..256: S = q*p + r
    q=0 (S=0):     0
    q=1 (S=p):     128   <-- sum Xi = 1 exactly
    q=2 (S=2p):    128   <-- sum Xi = 2 exactly
    other:         0
  sum Xi is integer: 256/256

  samples (n, S, q, r, sum Xi):
    n=1: S/p = 2  (q=2, r=0)
    n=2: S/p = 2  (q=2, r=0)
    n=5: S/p = 1  (q=1, r=0)
    n=7: S/p = 1  (q=1, r=0)
    n=17: S/p = 2  (q=2, r=0)

----------------------------------------------------------------------------------------
4) Wrap accounting
----------------------------------------------------------------------------------------
  Before reduction: x + beta*x + beta^2*x = x*(1+beta+beta^2)
  1+beta+beta^2 = 115792089237316195423570985008687907853269984665640564039457584007908834671663 = 1*p
  After reduction: xi' = beta^i*x - qi*p
  S = x*(1+beta+beta^2) - (q1+q2)*p
  If 1+beta+beta^2 = p, then S = p*x - (q1+q2)*p = p*(x - q1 - q2)
  so sum Xi = x - q1 - q2  (an integer; often 1 or 2 depending on wraps)

  wrap formula S = x(1+beta+beta2)-(q2+q3)p : 64/64 exact

----------------------------------------------------------------------------------------
5) If user rule: x1+x2+x3=p => sum Xi=1
----------------------------------------------------------------------------------------
  walk 1..256: triples with x1+x2+x3 == p : 128/256
  (all of those have sum Xi == 1 by construction)

========================================================================================
VERDICT
========================================================================================
  YES: x1+x2+x3=p  =>  X1+X2+X3=1 exactly in the coarse channel.
  GLV orbit sums to q*p with q usually 1 or 2 (wrap-dependent), not always p.
  When q=1, the three coarse channels sum to exactly 1 — a closed circle mod 1.
