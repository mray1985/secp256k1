THE BASE-3 ORIGIN RULE (FORMAL STATEMENT)
------------------------------------------

  s · k ≡ z + r · priv (mod N)

  x = (r · priv - z) mod N

  A = floor(x / 3) mod 3  (most significant digit, 3^1 place)
  B = x mod 3            (least significant digit, 3^0 place)

**Classification Rule:**
  Ω = +1  if B = 1
  Ω = 0   if B = 0 and A = 0
  Ω = -1  if B = 0 and A ∈ {1, 2}

**Equivalent Formulation:**

  Ω = +1 if x ≡ 4 (mod 9)

This is a DETERMINISTIC rule: given x mod 9, Ω is uniquely determined.
