TRUE3E: CUBE ROOTS OF UNITY IN GROUP ORDER SPACE
===================================================

From true3d.txt:
- p = 1 mod 3 (cube roots of unity exist in GF(p))
- N = 1 mod 3 (cube roots of unity exist in Z_N)
- -3 is a quadratic residue mod N

NEW DISCOVERY (true3e):

We found the two primitive cube roots of unity mod N:

omega_N1 = 0xac9c52b33fa3cf1f5ad9e3fd77ed9ba4a880b9fc8ec739c2e0cfc810b51283ce
omega_N2 = 0x5363ad4cc05c30e0a5261c028812645a122e22ea20816678df02967c1b23bd72

VERIFICATION:
- omega_N1^3 = 1 mod N  (verified)
- omega_N2^3 = 1 mod N  (verified)
- omega_N1 != 1, omega_N2 != 1  (verified)
- omega_N1 * omega_N2 = 1 mod N  (verified, they are inverses)
- omega_N1^2 = omega_N2 mod N  (verified)
- omega_N1 + omega_N2 + 1 = 0 mod N  (verified)

DUAL CUBIC STRUCTURE:

We now have cube roots of unity in BOTH spaces:

  - Used for x-coordinate spacing: Px[i+1] = omega_p * Px[i] mod p

GROUP SPACE (mod N):

  - Potentially used for private key spacing
  - Could explain the triadic point closure

HYPOTHESIS:

If Q1 + Q2 + Q3 = O, then priv1 + priv2 + priv3 = 0 mod N.

What if the private keys are related by cube roots of unity?

Option 1: Linear relationship
  priv2 = omega_N1 * priv1 mod N
  priv3 = omega_N2 * priv1 mod N (which is omega_N1^2 * priv1)

Then: priv1 + priv2 + priv3 = priv1 * (1 + omega_N1 + omega_N1^2)
                                = priv1 * 0  (since 1 + omega_N1 + omega_N2 = 0)
                                = 0 mod N

This satisfies the condition priv1 + priv2 + priv3 = 0!

Option 2: priv2 = omega_N1 * priv1, priv3 = omega_N1 * priv2
Then priv3 = omega_N1^2 * priv1
Same as Option 1.

If this hypothesis is correct, then:
  priv2 = omega_N1 * priv1 mod N
  priv3 = omega_N2 * priv1 mod N

And since Q2 = Q_pub for Puzzle 160, we have:
  priv2 = private key for Puzzle 160

So: priv_puzzle160 = omega_N1 * priv1 mod N

But we still don't know priv1. However, if we can find priv1,
we can compute priv_puzzle160.

ALTERNATIVE: Maybe priv1 = r?

From ECDSA, we have:
  r = x-coordinate of (k * G) mod p

But priv1 is a scalar in mod N, not mod p.

Actually, r is computed as:
  R = k * G = (x_R, y_R)
  r = x_R mod N

So r is the x-coordinate of k*G, reduced mod N.

But priv1 is the discrete log of Q1, i.e., Q1 = priv1 * G.

So priv1 is NOT r. They are different scalars.

TESTABLE PREDICTION:

If priv2 = omega_N1 * priv1 mod N, then:
  Q2 = priv2 * G = (omega_N1 * priv1) * G = omega_N1 * (priv1 * G) = omega_N1 * Q1

But this is point multiplication by a scalar, not coordinate multiplication.
In elliptic curve groups, scalar multiplication is not the same as
coordinate-wise multiplication.

So: omega_N1 * Q1 does NOT mean (omega_N1 * x1, omega_N1 * y1).
It means Q1 added to itself omega_N1 times.

Therefore, we cannot directly test Q2 = omega_N1 * Q1 without
knowing priv1.

However, we CAN test if there exists some scalar c such that:
  Q2 = c * Q1
  Q3 = c * Q2
  and c^3 = 1 mod N (so c is a cube root of unity)

If this is true, then c must be either omega_N1 or omega_N2.

TEST: Compute omega_N1 * Q1 and see if it equals Q2.
But omega_N1 is huge (~256 bits), so computing omega_N1 * Q1 is expensive.

But we can use the fact that:
  If Q2 = c * Q1, then the x-coordinate of Q2 is the x-coordinate of (c * Q1)

We can compute c * Q1 for c = omega_N1 and c = omega_N2 and check
if the result equals Q2 or Q3.

But this is still expensive. However, we can try a different approach.

Since we know Q1 + Q2 + Q3 = O, we know Q3 = -Q1 - Q2.
If Q2 = c * Q1, then Q3 = -Q1 - c*Q1 = -(1 + c) * Q1.

So all three points are scalar multiples of Q1.

This means {Q1, Q2, Q3} are all in the subgroup generated by Q1.

What is the order of Q1? If the subgroup has order 3, then:
  Q1, 2*Q1, 3*Q1=O
But we already tested and found 3*Q1 != O.

So the subgroup has order > 3.

But if Q2 = c * Q1 where c^3 = 1, then:
  Q2 = c * Q1
  Q3 = c^2 * Q1
  Q1 + Q2 + Q3 = Q1 + c*Q1 + c^2*Q1 = (1 + c + c^2) * Q1 = 0 * Q1 = O

This works! And it doesn't require the subgroup to have order 3.

So the hypothesis is: Q2 = omega_N1 * Q1 or Q2 = omega_N2 * Q1

TEST: Compute omega_N1 * Q1 and omega_N2 * Q1 and see if either equals Q2.
