3. Test correlation:
   Omega = +1  =>  (r*priv - z) mod 3 = ?
   Omega = -1  =>  (r*priv - z) mod 3 = ?
   Omega = 0   =>  (r*priv - z) mod 3 = ?

Expected result: A clean mapping like:
   Omega = +1  =>  (r*priv - z) = 1 mod 3
   Omega = -1  =>  (r*priv - z) = 2 mod 3
   Omega = 0   =>  (r*priv - z) = 0 mod 3

This would establish that Omega originates from a triadic partition
in the initialization parameters, driven by secp256k1's structure
(p = 1 mod 3, N = 1 mod 3).
