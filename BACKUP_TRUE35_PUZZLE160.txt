7. ALGORITHM TO FIND d AND k FOR PUZZLE 160
================================================================================

Given:
  - r, s, z (known from true28.txt)
  - Range: d ∈ [2^159, 2^160-1] ∪ [N-2^159, N-2^160-1]
  - ECDSA equation: s·k = z + r·d (mod N)
  - Point equation: k·G = (r, y) where y is known from compressed x

Approach:
  1. Compute y from compressed x (02 prefix = even y)
     y = sqrt(r^3 + 7) mod p, choose even parity
  
  2. Now we know R = (r, y) = k·G
     This means k is the discrete log of R base G
  
  3. From ECDSA: k = (z + r·d) · s^-1 mod N
     Substitute into point equation:
     ((z + r·d) · s^-1) · G = (r, y)
  
  4. Rearrange: (z + r·d) · (s^-1 · G) = (r, y)
     Let H = s^-1 · G (a point on the curve)
     Then: (z + r·d) · H = (r, y)
  
  5. This is still a discrete logarithm problem, but we have the range constraint
     on d. For each candidate d in the range, we can:
     - Compute k = (z + r·d) · s^-1 mod N
     - Compute k·G
     - Check if x(k·G) = r
  
  6. The range has size 2^159 which is infeasible to brute force
  
  7. Therefore, we use the Star of David candidates:
     - cand1 = rx3 mod N
     - cand2 = (rx3 * Lambda^-1) mod N
     - cand3 = d3
     - cand4 = (rx3 * d3^-1) mod N
     - cand5 = (cand4 * delta_k) mod N
     where:
       - Lambda = Px3 * rx3^-1 mod p
       - delta_k = r * s^-1 mod N
       - d3 is a cube root of Delta = p - N
  
  8. Test each candidate with the ECDSA verification:
     - Compute k = (z + r·d_candidate) · s^-1 mod N
     - Compute k·G
     - Check if x(k·G) = r
     - Check if d_candidate falls in the expected range
     - Compute (r·d - z) mod 3 for Origin Rule test
