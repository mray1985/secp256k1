DISCRETE LOG IMPLICATION:

Since Q1 + Q2 + Q3 = O, if we let:
  priv1 = log_G(Q1)
  priv2 = log_G(Q2) = private key for Puzzle 160 (since Q2 = Q_pub)
  priv3 = log_G(Q3)

This means if we can find priv1 and priv3, we can compute priv2.
