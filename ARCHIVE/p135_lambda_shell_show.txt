 RIGHT ratio laws (separate layers)
------------------------------------------------------------------------
  LAW-P:  lam_y^2 == (Px^3+7)/(rx^3+7)   mod p?  True
  LAW-X:  lam_x^3 == (Py^2-7)/(ry^2-7)   mod p?  True

  Expand LAW-P:
    lam_y^2 * (rx^3+7) = Px^3+7
    check mod p: True

  Expand LAW-X:
    lam_x^3 * (ry^2-7) = Py^2-7
    check mod p: True

------------------------------------------------------------------------
 WEIGHTED GLUE (why +7 appears)
------------------------------------------------------------------------

  lam_y = Py/ry   =>  lam_y^2 * ry^2 = Py^2
  lam_x = Px/rx   =>  lam_x^3 * rx^3 = Px^3

  lam_y^2*ry^2 - lam_x^3*rx^3
       = Py^2 - Px^3
       = 7           (mod p)
       = G           (mod N)

  mod p value: 7
  mod N value: 84598352132466870527143686503981636492449086335144718550646429568820732186027
  K = N-G:     31193737104849324896427298504706271360388477943930185831958733572697429308310
  Py^2 + K == Px^3 mod N? True
