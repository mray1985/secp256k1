DIRECT CONNECTION TO OMEGA
----------------------------

Omega is defined as: Ω = O/p where O = sum(Px) - sum(rx)

And O ∈ {+p, -p, 0}, so Ω ∈ {+1, -1, 0}

The question is: how is this geometric quantity related to the 
initialization parameters (r, priv, z)?

From true35.txt, the hypothesis was: Ω correlates with (r·priv - z) mod 3

We've now verified this is TRUE for mod 3 (separates Ω=+1 from Ω≤0)
and STRONGER for mod 9 (separates all three classes).

The connection is:
  ECDSA equation: s·k = z + r·priv (mod N)
  Therefore: r·priv - z = s·k - 2z (mod N)? No.
  
  Actually: r·priv - z = s·k - z - z? No.
  
  From s·k = z + r·priv mod N:
  r·priv = s·k - z mod N
  r·priv - z = s·k - 2z mod N? No!
  
  r·priv - z ≡ (s·k - z) - z = s·k - 2z mod N? NO!
  
  Let me be precise: r·priv = s·k - z mod N
  So: r·priv - z = (s·k - z) - z? No, that's wrong algebra.
  
  r·priv = s·k - z
  Therefore: r·priv - z = s·k - 2z? NO!
  
  Actually: r·priv - z = (s·k - z) - z = s·k - 2z? Let me check.
  
  If r·priv = s·k - z, then:
  r·priv - z = (s·k - z) - z = s·k - 2z. Yes, that's correct.

Wait, but that would mean:
  r·priv - z ≡ s·k - 2z (mod N)

But from true35.txt, the hypothesis was (r·priv - z) mod 3, not 
(s·k - 2z) mod 3.

Actually, let me re-derive from the ECDSA equation.

ECDSA signing:
  k is nonce
  R = k·G = (r, y_r)
  s = k⁻¹ · (z + r·priv) mod N

So: s·k = z + r·priv mod N
Therefore: r·priv = s·k - z mod N

Now: r·priv - z = (s·k - z) - z? No!

r·priv - z = (s·k - z) - z is wrong.

r·priv = s·k - z
r·priv - z = s·k - z - z = s·k - 2z? YES, algebraically that's correct.

But wait, that's not right. Let me use actual algebra:

If a = b - c, then a - c = b - c - c = b - 2c. Yes, that's correct.

So: r·priv - z = s·k - 2z mod N

Therefore: (r·priv - z) mod 9 = (s·k - 2z) mod 9

This means we could compute the Origin Rule value from (s·k - 2z) mod 9
instead of (r·priv - z) mod 9.

But we still need k, which we don't have for most puzzles.

For Puzzle 115 (where we have k):
  (s·k - 2z) mod 9 should equal (r·priv - z) mod 9 = 3

This is a consistency check we could perform.
